Проекты

promptdiff

Сравнивает варианты промпта на наборе задач.

  • Python
  • asyncio
  • httpx
Подробнее

Прогоняет несколько вариантов промпта по одним и тем же задачам и показывает, где ответы разошлись: на каких задачах один вариант прошёл проверки, а другой нет.

  • Чёткие проверки ответов вместо оценки на глаз
  • Асинхронные запросы с повторами, ограничением частоты и паузой по retry-after
  • Кэш ответов на диске и цена каждого варианта через token-counter
  • Два поставщика: Anthropic и Groq с бесплатным уровнем

doc-answers

Ответы по вашим документам со ссылкой на источник.

  • Python
  • RAG
  • BM25
Подробнее

Отвечает на вопросы по папке со своими документами строго по найденным кускам, со ссылкой на источник, а если ответа нет, так и говорит.

  • Поиск BM25 по основам слов, без векторной базы
  • Ссылки модели на источники проверяются кодом после ответа
  • Набор вопросов отдельно проверяет поиск и ответы модели
  • Демонстрационный режим без ключа

gost-skills

Проверяет оформление курсовых и отчётов в .docx по ГОСТу и показывает, где ошибка.

  • Python
  • python-docx
  • Agent Skills
Подробнее

Навыки для ИИ-агентов со стандартом Agent Skills: Claude Code, Codex, Cursor и других. Скрипт читает готовый файл .docx и называет каждое нарушение ГОСТ 7.32 с номером абзаца и пунктом стандарта.

  • Поля, шрифт, интервалы, заголовки, подписи рисунков и таблиц, ссылки на источники
  • Свойства текста ищутся по цепочке стилей, как их видит Word
  • Настройки под методичку в TOML поверх профиля ГОСТ
  • Тесты на файлах, собранных кодом, и проверка SKILL.md по спецификации
